# Function
```text
✔️함수
    - 특정한 작업을 수행하는 코드 묶음
    - 필요시 호출하여 반복 사용 -> 재사용율 증가
    - 재사용성, 간결성, 유지, 보수 효율성 증가

✔️동작 개념
    input -> 함수 -> output
    (Argument(인자값) -> f(x) -> return)

✅Abstrction (추상화)
    내부 구현을 감추고, 필요한 기능만 사용할 수 있게 하는 것
    (내부 동작을 몰라도 입력, 출력만 알면 사용 가능)

✔️함수 분리 시기
    1) 같은 코드가 반복 될 때
    2) 하나의 기능으로 의미 있게 분리 가능할 때
    3) 나중에 다시 사용 가능성이 있을 때
    4) 코드가 길어 구조 파악이 어려울 때
        ○ 기능별로 나누어 가독성 🔝
✅실무 
    1) 함수 1개 : 한 가지 일만 담당 (단일 책입 원칙)
    2) 함수 이름은 동사 or 동사구로 작성
    ex) calculate_average, get_user, print_result
    

✔️ 핵심정리
    • 함수 = 작업을 묶어 재사용하는 단위 (def로 정의, 이름으로 호출) 
    • 매개변수(받는 변수) 인자값(전달하는 값) - 정의/호출의 차이 
    • 지역변수는 함수 호출 시 생겼다가 종료 시 사라진다 (스택) 
    • return으로 결과 반환, 값이 여러 개면 튜플로 묶여 나온다 
    • 매개변수 정의 순서 : 필수 매개변수 → 기본값 매개변수 → *args → **kwargs
    • 함수 호출 시 인자값 전달 순서: 위치 인자값 → 키워드 인자값 • 받을 땐 묶기(packing), 보낼 땐 풀기(unpacking) 
    • 좋은 함수 : 한 가지 일만, 이름은 동사로, 전역변수 의존 최소화
```
