# Definition & Call (정의와 호출)
```text
✔️Definition (정의)
    - def 키워드 사용 (define 약자)

✔️형식
    def 함수 이름(매개변수):
        함수 내용
        
        ○ 함수 이름: 기능이 드러나는 동사 or 동사구
        ○ parameters (매개변수): 입력을 받는 변수 (없을 경우 생략 가능)
        ○ 콜론(:): 함수 본문의 시작
        ○ 본문: 들여쓰기로 블럭 구분
        ○ return(반환): 결과를 반환 (생략 가능)
    
✔️실행 흐름
    1) 함수(매개변수) 호출 -> 2) 함수 본문 실행 
    
✔️매개 변수, 인자값
    - 매개변수: 함수를 정의 할때 ()의 작성하는 변수
인자값: 함수를 호출할 때 전달하는 값
```
