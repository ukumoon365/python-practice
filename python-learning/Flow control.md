# Flow control (흐름 제어)
```text
프로그램의 실행 흐름을 제어하는 기능
기본적 위에서 아래로 실행


✔️순차 실행
        ○ 작성된 순서대로 위에서 아래로 실행 ⬇️

✔️선택문
        ○ if (조건이 참일 때만 실행)
        『if 조건식:
            실행 블록』 
            § : 다음 줄은 들여쓰기
            § 조건식이 True이면 실행 / False이면 실행 하지 않음
            § 특정 조건을 만족할 때만 실행 용도
            
        ○ if - else (두 조건 중 하나를 선택)
        『if 조건식:
            실행 블록 1
         else:
            실행 블록 2』
            § 조건식이 True면 실행 블록 1 실행
            § 조건식이 False면 실행 블록 2 실행
            § 선택지 2개 중 하나를 반드시 결정할 때 사용 
        
        
        ○ if - elif - else (여러 조건 중 하나를 선택)
        『if 조건식:
            실행 블록 1
        elif 조건식:
            실행 블록 2
         else:
            실행 블록 3』
            § 조건을 위에서부터 차례대로 검사 ⬇️
            § 처음 True가 되는 블록 하나만 실행 / 밑에 조건은 검사 ❌
            § elif는 여러 개 작성 가능 ♾️
            § else: 는 선택 사항 
            
    ✔️중첩 if문
        『if 조건식:
            if 조건식:
             실행 블록 1』
            § 바깥 조건 검사 후 True일 때만 안쪽 조건 검사
            § 조건을 단계적으로 나누어 판단 할 때 사용
            § 많은 중첩 if문은 가독성 ⬇️
          ⬇️
            § 여러 조건 모두 True일 때 결과가 하나 뿐이면 
            and 연산자 사용으로 간결하게
            § elif 체인으로 평탄화 
            
✔️반복문
        ○ for (같은 코드 블록 여러번 실행)
            § range() 함수 -> 『for 변수 in range(횟수):
                            실행 블록 』 
                □ range(start, end, step) / slicing
                    ® start -> index 0 부터  n - 1까지
                    ® start, end -> start <= X < end
                    ® start, end, step -> step만큼 증가
            § 시퀀스 순회 -> 『for 변수 in list, str, tuple, dict, set ...:
                            실행 블록』
                    ® 순회 가능한 모든 시퀀스에 for 사용 가능
            § enumerate() 인덱스와 요소가 함께
            § zip() 여러 시퀀스 같이 보기
            § 반복 횟수가 정해져 있을 때 / 컬렉션 순회 / 반복 누적 처리에 자주 쓰임 
            
        ○ while (조건이 True인 동안 반복)
            § 『while 조건식:
                실행 블록』 
            § 조건 검사 -> 블록 실행 -> 조건 검사 무한 반복
            § 주의사항 ⚠️
                □ 무한 루프 가능성 ♾️
                □ 처음 조건이 True가 될 수 있는지 확인
                □ 조건 변수가 변화 확인
                □ 조건이 False이 되는 지 확인
                
        ✔️중첩 반복
            § 2차원 구조 순회 / 계층적 반복 / 조합, 쌍 탐색 / 패턴 생성
                □ 『for 바깥변수 in 바깥범위:
                    for 안쪽변수 in 안쪽 범위:
                        실행블록』
                □ 바깥 반복문이 1회 실행 되는 동안 안쪽 반복문은 끝까지 실행됨
                
        ✔️반복 제어
            § break 
                □ break를 만나면 즉시 반복 종료 및 탈출
                □ 더 이상 반복이 필요 없을 때 사용
                □ ⚠️ break를 감싼 가장 안쪽 반복 하나만 탈출함 / 중첩 반복일 때 주의
                    ® 모든 반복을 한번에 끝내고 싶다면
                        i) 플래그 변수
                        find = False -> if find: break 
                        ii) 함수로 감싼 후 return으로 함수 탈출
                        def find():
                            return
            § continue
                □ 이번 반복 건너뛰기
특정 조건일 때만 처리를 건너뛸 때 사용
```
