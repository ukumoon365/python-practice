# Comment (주석)
```text
# Comment (주석)

코드의 설명을 적는 메모
    가독성 🔝
    프로그램 실행 영향 ❌
    
사용 목적
    - 코드 설명
    - 개발자 메모
        ○ TODO (추후 개발 항목)
        ○ FIXME (수정 사항)
    - 참조 정보
        ○ 코드 관련 문서
        ○ 참고 링크
    - 디버깅
        ○  일부 코드 제외
        ○  오류 원인 분석 활용
        
사용 방법
    - # 기호 사용
        ○ 한 줄 주석
            § 한 줄 끝까지 주석 처리
        ○ 인라인 주석 
            § 코드 오른쪽에 짧은 설명 추가
        ○ 여러 줄 설명
            § 여러 줄에 # 붙여서 사용
    - """ """ or ''' ''' (Docstring)
        ○ 함수 / 클래스 / 모듈 설명
```
