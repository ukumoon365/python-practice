# Operator (연산자)
```text
일정한 규칙에 따라 식을 계산하는 것
Operator(연산자) and Operand(피연산자)로 구성

    - 연산자 기능별 분류
    ✔️산술 연산자
            +, -, *, /, //(몫), %(나머지), **(거듭제곱)
            § 문자열  + 연결 연산자 / * 반복 연산자
            
    ✔️비교 연산자 
            ==, !=, >, <, >=, <=
            § 두 값을 비교하는 이항 연산자
            § 결과값은 항상 Boolean(불린형)
        

    ✔️논리 연산자
            and, or, not
            § True, False 이용한 조건 결합 연산자
        
        
    ✔️대입 연산자
            § 값을 변수에 저장하는 연산자
            § = 는 대입 / ==는 비교
        ○ 복합 대입 연산자
            § +=, -=, *=,  /=
            § 기존 값이 있어야 사용 가능
            x = 0     # 기존 값
            x += 1
            § 변수 초기화 용도 ❌
            
        ○ 다중 대입 연산자 (tuple)
            § 여러 변수를 한 줄로 값을 대입
                □ ,로 구분  
            x, y = 5, 10
            
    - 피연산자 개수에 따른 연산자 구분
    ✔️단항 연산자
        ex) not True    # Flase
            x = 10
            -x  (부호 반전)
    ✔️이항 연산자
        ex) 10 + 3 
            10 > 3  # True
            True and False  # False
        
    ✔️삼항 연산자
        ex) result = "합격" if score >= 70 else "불합격"
                
    ○ 우선 순위 단항 > 이항
        
    ✔️이항 연산시 묵시적 형변환
            § int + float -> int가 float으로 변환
            § int + bool -> True -> 1 / False -> 0 변환
            § str + int -> Type Error
            § str + str / str * 3 -> 연결 연산자, 반복연산자로 변환
            § 조건식 판별 -> 값을 boolean으로 변환

        ○ 자료형 확인이 필요한 이유
            § 비트 단위 처리
                □ cpu는 모든 데이터를 비트 단위로 처리
                □ 자료형 마다 메모리 저장 방식 및 비트 해석 방식이 다름
                -> 묵시적 형변환으로 해결
```
